# Procedural Generation Systems

This document describes the procedural generation techniques, seeded noise fields, cellular automata terrain synthesis, and particle dispersion patterns used across **ARCADE_** (`core/math/noise.ts`, `core/algorithms/cellularAutomata.ts`).

---

## 1. Seeded 2D Gradient Value Noise (`core/math/noise.ts`)

The `ValueNoise` engine creates smooth, continuous 2D heightmaps for procedural terrain (*Infinite Forest*, *Cave Escape*):

```text
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│ Seed Integer │ ---> │ Shuffled     │ ---> │ Hermite      │ ---> Continuous
│ (e.g. 1337)  │      │ Permutation  │      │ Smoothstep   │      Gradient [0, 1]
└──────────────┘      └──────────────┘      └──────────────┘
```

### Noise Formulation
For any point $(x, y)$ in world coordinates:
1. Identify grid cell $(x_i, y_i) = (\lfloor x \rfloor, \lfloor y \rfloor) \pmod{256}$.
2. Look up pseudorandom values at the 4 cell vertices from the permutation table.
3. Compute fractional coordinates $u = \operatorname{smoothstep}(x - \lfloor x \rfloor)$ and $v = \operatorname{smoothstep}(y - \lfloor y \rfloor)$.
4. Bilinearly interpolate between the four corners:

$$\text{Noise}(x, y) = (1 - v)\left[(1 - u)V_{00} + uV_{10}\right] + v\left[(1 - u)V_{01} + uV_{11}\right]$$

## 2. Cellular Automata Cave & Maze Generation

Organic cave structures are generated by initializing a grid with random boolean noise and iteratively applying the **Cave Smoothing Rule** (`core/algorithms/cellularAutomata.ts`):

```typescript
export function caveRule(current: number, neighbors: number[]): number {
  const walls = neighbors.filter((n) => n === 1).length;
  // If wall: stay wall if >= 4 neighbors. If empty: turn into wall if >= 5 neighbors.
  return current === 1 ? (walls >= 4 ? 1 : 0) : (walls >= 5 ? 1 : 0);
}
```

By running 4 to 5 iterations of this rule across a $40 \times 30$ grid, random noise self-organizes into natural cavern pathways and subterranean chambers.

## 3. Stochastic Fire & Fluid Dynamics

### Probabilistic Fire Spread
```typescript
export function fireRule(prng: () => number, spreadChance: number = 0.3) {
  return (current: number, neighbors: number[]): number => {
    if (current === 2) return 3; // burning -> burnt
    if (current === 3) return 3; // burnt stays burnt
    if (current === 1) {
      const burning = neighbors.filter((n) => n === 2).length;
      if (burning > 0 && prng() < spreadChance) return 2;
    }
    return current;
  };
}
```

*Applied in:* `Fire Spread`, `Liquid Cells`, `Sand World`.
